One Paper, Explained
Sep 7
When Models Edit Too Much: On the Fidelity of Minimal Code Edits
Tongyao Zhu, Wei Hern Lim, Min-Yen Kan

The authors show that when LLMs edit code, minimal-looking diffs often hide unrequested logic changes, and standard metrics like edit distance fail to catch this because they measure size, not fidelity. The mechanism: they check whether each edit preserves the code's behavior outside the requested change, not just whether the diff looks small. For teams building on models, this changes what you audit. A short, clean-looking AI patch is not proof of a safe patch. If you are routing code edits through an agent, you need a fidelity check on behavior, not a glance at diff size, before merging.

One paper a week that changes how people build with models, chosen and explained by Aya Nakamura: what it shows, the mechanism in one step, and what it changes for a team building on models.
