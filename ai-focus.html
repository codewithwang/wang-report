One Paper, Explained
Sep 13
Memory as Plans: World-Action Modeling with Memory-Grounded Planning
Sizhe Zhao, Haozhe Xie, Weiyu Zhao

Sizhe Zhao and coauthors show that giving an AI agent a persistent memory of past experience does more for planning than giving it a bigger model or more search. The mechanism: instead of retrieving raw past states, the system stores them as compressed action plans, so the agent recalls what to do next rather than what it once saw. For a team building agents, this changes the engineering target: stop scaling inference-time search or context length and start building a memory layer that indexes prior successful plans for reuse. It reframes memory as a planning component, not a retrieval add-on, which matters for anyone shipping long-horizon agents where compute cost per decision is the actual bottleneck, not raw model capability.
