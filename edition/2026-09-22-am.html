    • The response so far is architecture, not apology. AWS has spent the past week publishing the plumbing regulated firms are supposed to build before they hand an agent that kind of reach: per-tool authorization gateways for Amazon Quick that check identity claims before a model touches an MCP tool (AWS Machine Learning, 2026-09-17), and a shared runtime for Wood Mackenzie on Bedrock AgentCore that centralizes logging and guardrails so no team ships an agent without a trace (AWS Machine Learning, 2026-09-17). The Gemini spree is what happens when a lab ships an agent before it ships the authorization layer the rest of the industry is now racing to bolt on after the fact.
